# إعادة التنظيم التدريجي — المرحلة الأولى

## الأساس

- المستودع: MIKASSO1/pdflexi.
- نسخة الأساس: `cdbde995c216f3eb9c92e255091743a0c355a87c`، من الفرع `feature/phase-1-interface`.
- هذه تغييرات محلية، وليست تغييرات منشورة على GitHub.

## المنفذ

- فصل دورة حياة المرفقات في مخزن مستقل عن React، مع محول React رقيق.
- فصل حالة المحادثة والمسودة عن App؛ الرد الحالي إقرار تجريبي وليس نتيجة تنفيذ أداة.
- استخراج انتقالات سجل التعديلات إلى وظائف نقية واختبارها مباشرة.
- تخزين تواقيع اللقطات غير القابلة للتغيير مؤقتاً، بدلاً من إعادة تسلسل جميع المستندات عند كل فحص لحالة الحفظ.
- فصل خدمة تصدير PDF عن هندسة الرسم، واستخراج إدارة عملية التنزيل إلى hook مستقل.
- منع استعادة ملف محذوف بسبب قراءة غير متزامنة لملف آخر.
- إبطال عمليات إضافة الملفات المعلقة عند التخلص من المخزن، وتحرير روابط الملفات.
- منع اكتمال تصدير متأخر من إعادة إنشاء حالة مستند محذوف، أو اعتبار تعديلات أحدث محفوظة.
- إضافة 14 اختبار وحدة إلى الاختبارات السبعة السابقة، وإضافة workflow للبناء والاختبارات واختبارات المتصفح.

## التحقق المحلي

- TypeScript: ناجح.
- اختبارات الوحدات: 21 من 21.
- اختبارات المتصفح: 21 من 21، على Chromium المحلي ضد بناء الإنتاج.
- البناء والتنسيق و`git diff --check`: ناجحة.
- لم يُختبر تشغيل GitHub Actions المستضاف؛ يبدأ بعد رفع التغييرات، وفق إعدادات المستودع.
- الاختبارات المحلية ليست تدقيقاً أمنياً أو اختبار تحميل شاملاً، ولم تشمل جميع المتصفحات والأجهزة.

## تطبيق ملف Patch على نسخة Git موجودة

احفظ عملك الحالي أو اعمل من نسخة نظيفة أولاً. نفّذ الأوامر من مجلد المشروع، واستبدل مسار ملف Patch بموقعه الحقيقي:

```sh
git status --short
git switch -c refactor/feature-boundaries
git apply --check /path/to/pdflexi-refactor.patch
git apply /path/to/pdflexi-refactor.patch
npm ci
npm run typecheck
npm test
npm run build
npm run format:check
```

إذا فشل `git apply --check` فلا تجبر التطبيق ولا تستبدل ملفاتك عشوائياً؛ قد تكون نسخة المستودع تغيرت عن نسخة الأساس. راجع الفروق أولاً.

لاختبارات المتصفح:

```sh
npm exec -- playwright install chromium
npm run preview
# من طرفية ثانية:
TEST_URL=http://localhost:4173 npm run test:e2e
```

ثم راجع التغييرات قبل حفظها ورفعها في فرع مستقل:

```sh
git diff
git add .
git commit -m "refactor: separate attachment, conversation and editor lifecycles"
git push -u origin refactor/feature-boundaries
```

## النسخة المصدرية داخل الأرشيف

مجلد `pdflexi/` يحتوي المصدر الكامل المعدل دون `.git` أو `node_modules` أو `dist`. شغّل `npm ci` ثم `npm run dev` لمراجعته بصورة مستقلة. لا تستبدل به عملاً أحدث في مستودعك دون مقارنة. استخدم ملف Patch أو دمجاً يدوياً إذا كان هناك عمل قائم.

## ما لم تنفذه هذه المرحلة

- لم تتم إضافة نموذج ذكاء اصطناعي أو محركات تنفيذ الأدوات الثلاثين.
- لم تتم إضافة مخططات تحقق لكل أداة، أو منسق مهام الوكيل، أو عزل المعالجة في Workers.
- لم تتم إضافة حفظ تلقائي للمسودات، أو محاكاة افتراضية كاملة للصفحات، أو خادم أو اشتراكات.
- بقي تنسيق التصدير الحالي: إضافات بصرية مسطحة، وليس تحرير النص الأصلي أو التنقيح الآمن.

هذه مرحلة تأسيس قابلة للمراجعة والاختبار، وليست إعلان جاهزية المنصة الكاملة للإطلاق.
