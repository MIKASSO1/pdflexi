# تسليم PDFlexi

## ما يعمل الآن

- شاشة بداية ببطاقة واحدة: المستند ومعاينته على اليسار وكتابة الطلب على اليمين. على الهاتف يُرتّبان عموديًا. جميع الأدوات متاحة من زر واحد بدل إظهار قوائم مزدحمة.
- رفع الملف وحده لا يفتح الورشة. أول طلب مع ملف يفتح الشات بجانب المستند.
- PDF يفتح على وضع «الصفحة كاملة». توجد أزرار تكبير وتصغير، عرض الصفحة، ونسب 100% وغيرها. عدّاد الصفحات حقيقي والتمرير يصل إلى آخر المستند.
- أدوات يدوية حقيقية: التحديد والتحريك، إضافة نص، رسم، تظليل مستطيل، مستطيل، سهم، وممحاة للإضافات.
- تنسيق النص المضاف: نوع الخط وحجمه، عريض ومائل وتسطير، محاذاة ولون، ونص متعدد الأسطر. لتغيير نص مضاف، حدّده ثم اختر أداة النص واضغط تطبيق بعد تعديل الخصائص.
- تراجع وإعادة وحذف الإضافة المحددة. المسودات مستقلة لكل ملف وتبقى متاحة عند التكبير أو التبديل بين الملفات.
- تنزيل PDF معدّل كنسخة منفصلة. النصوص والرسومات المضافة تُدمج في طبقة صورة، مع الحفاظ على المحتوى الأصلي تحتها. تنزيل الأصل يُرجع نفس البايتات بلا تغيير.
- تأكيد قبل إزالة ملف له تعديلات غير مُصدّرة، وتحذير عند مغادرة التبويب مع مسودة.
- العربية والإنجليزية والفرنسية، وسجل 29 لغة يبيّن أن بقية اللغات مخططة فقط.
- جميع القدرات الثلاثين موجودة لصياغة الطلبات: 20 مجانية، منها OCR، و10 احترافية. تنفيذها التلقائي بالذكاء الاصطناعي غير مربوط بعد.

## حدود مهمة

الممحاة تزيل إضافات المستخدم فقط، ولا تمسح النص الأصلي ولا تؤدي حجبًا آمنًا. المحرر لا يعيد كتابة النص الأصلي داخل أي PDF. النص المضاف في النسخة المُصدّرة يكون جزءًا من صورة، وليس نص PDF قابلًا للتحديد أو تعديلًا تفاعليًا عند إعادة فتح النسخة. قد تفقد التواقيع الأصلية صلاحيتها في النسخة المعدّلة.

الملفات والمحادثة والمسودات في ذاكرة التبويب فقط. يجب تنزيل النسخة للاحتفاظ بالتعديلات؛ لا يوجد حفظ سحابي تلقائي أو استمرار للمسودة بعد تحديث الصفحة. الملف الأصلي لا يُستبدل. معالجة الذكاء الاصطناعي والتحويل وOCR والحسابات والدفع والحصص ليست مفعّلة. ملفات Word وExcel تُرفق فقط ولا تُحوّل بهذه الأدوات.

## التشغيل

يتطلب Node.js 22 أو أحدث. من مجلد المشروع:

```bash
npm install
npm run dev
```

افتح رابط المنفذ 5173 من Ports في Codespaces، أو الرابط المحلي الذي يظهر في الطرفية. لا حاجة إلى مفاتيح API.

## جلب التحديث

احفظ تغييراتك المحلية أولًا، ثم أوقف السيرفر بـ Ctrl+C وشغّل:

```bash
git pull origin feature/phase-1-interface
npm install
npm run dev
```

## الفحص والنشر

```bash
npm run typecheck
npm test
npm run build
npm run format:check
# مع تشغيل سيرفر التطوير:
CHROMIUM_PATH=/path/to/chromium npm run test:e2e
```

الاختبارات تولّد ملفات PDF وتتحقق من الأدوات والتصدير وإعادة عرض الملف المعدّل، ومن حفظ الأصل ومحاذاة الإضافات في الصفحات المقصوصة والمدوّرة. الصور والنتائج في `artifacts/qa/` غير المتتبّع.

للنشر، ارفع محتويات `dist/` إلى مستضيف ثابت مناسب. رفع الكود إلى GitHub ليس نشرًا تلقائيًا لموقع إنتاجي. راجع `SECURITY.md` قبل إطلاق تجاري.
