# تسليم واجهة PDFlexi — المرحلة الأولى

## ما تم بناؤه

- مساحة عمل بأعمدة على الحاسوب، وقوائم للقدرات على الهاتف.
- جميع القدرات الثلاثين في سجل موحّد: 20 تقليدية و10 ذكية.
- اختيار الأداة يصوغ طلبًا في المحادثة؛ لا يفتح محرّرًا يدويًا.
- محادثة بارتفاع 620px مع منطقة رسائل قابلة للتمرير وحقل إدخال ثابت داخلها.
- إرفاق ومعاينة محلية لملفات PDF والصور، وإرفاق Word وExcel دون ادّعاء تحويلهما.
- معاينة موسّعة، وتنزيل الأصل، وإزالة المرفقات، وواجهة سجل النسخ التي توضح عدم وجود نسخ معالجة بعد.
- واجهات الإنجليزية والعربية والفرنسية، مع تأسيس سجل 29 لغة وإظهار باقي اللغات كمخطّطة وغير مفعّلة.
- واجهات شرح الاستخدام والخصوصية والباقات المخطّطة.
- توثيق المعمارية والمراحل والأمان، واختبارات تلقائية، وقالب اختياري لفحص البناء عبر GitHub Actions في docs/ci-template.yml؛ القالب غير مفعّل حاليًا.

## حدود هذه النسخة

هذه واجهة وليست خدمة معالجة PDF أو ذكاء اصطناعي مكتملة. استلام الطلب ليس تنفيذًا له. لا تعديل للملفات، ولا ربط بنموذج، ولا تحويل أو OCR، ولا دفع أو حسابات أو إعلانات أو حصص مفروضة. الملفات والمحادثات لا تُحفظ بعد إعادة تحميل الصفحة. تفضيل اللغة فقط قد يُحفظ محليًا.

حدّ المعاينة الحالي 10 ملفات، بحدّ 20 MiB لكل ملف؛ لا يعني ذلك تفعيل خدمة ختم 100 وثيقة. المكتبات ومحركات المعالجة وخطة توزيع نموذج محلي ستُراجع في المراحل التالية ضمن الميزانية المتاحة.

## التشغيل

```bash
npm ci
npm run dev
```

## الفحوصات

```bash
npm run format:check
npm test
npm run build
```

تشغيل اختبارات المتصفح موثّق في README. نجحت 7 اختبارات وحدات و17 سيناريو متصفح في بيئة Chromium المحلية. هذا لا يغني عن الاختبار لاحقًا على هواتف حقيقية وSafari وFirefox أو المراجعة الأمنية المستقلة، ولا يثبت تحمّل 60 ألف زائر يوميًا.

## الخطوة التالية

مراجعة التصميم واعتماده، ثم المرحلة الثانية لربط محركات معالجة الملفات. لا تتطلب هذه الواجهة مفتاح API أو خدمة مدفوعة. لا يوجد نشر حي أو دومين مربوط تلقائيًا.
